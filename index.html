Un cadeau de Hugo

Salut Aloïs, moi c'est Claude.

Hugo m'a demandé de te faire ce petit site. Il m'a dit que tu ne t'y connaissais pas trop en informatique : tant mieux, tout est expliqué simplement. À la fin, tu auras ton propre site internet en ligne, ce soir, et c'est moi qui l'aurai écrit à ta place.

Le mot d'ordre de Hugo : prends ça comme un jeu vidéo. Tu ne seras pas Bill Gates demain, et ce n'est pas le but. Essaie, rate, recommence, amuse-toi bien. 🎮
Les étapes Ce que je sais faire

Je suis quoi, exactement ?

Je suis une intelligence artificielle, créée par la société Anthropic. Concrètement : tu m'écris comme à un ami qui sait beaucoup de choses, et je te réponds. Je peux t'expliquer, résumer, traduire, corriger, chercher des idées… et surtout écrire du code, c'est-à-dire le « texte secret » qui fait fonctionner un site, un jeu ou une application.

C'est ça le truc magique : tu n'as pas besoin de savoir coder. Tu me dis en français ce que tu veux (« un site avec une photo, ma présentation et un bouton pour me contacter »), et je te le fabrique.

💬 Tu parles, je construis

Pas de jargon. Décris ton idée comme tu la raconterais à un pote.

🔁 On ajuste ensemble

« Plus sombre », « plus gros », « ajoute une galerie » : je corrige en quelques secondes.

📚 J'explique aussi

Si un mot te perd, demande-moi. Je te l'expliquerai autrement, autant de fois que nécessaire.

Ton premier site, en 6 étapes

Vois ça comme les niveaux d'un jeu : chaque étape débloque la suivante. Pas de pression, pas de mauvaise réponse, tu peux toujours recommencer le niveau.

⏱ Compte 1 h à 1 h 30 la première fois, en prenant ton temps. Il y a un petit guide pas à pas pour chaque étape.

1

Installer Claude

Trois façons de m'utiliser, toutes avec le même compte :

  • Sur ordinateur : va sur claude.ai, tu peux aussi télécharger l'application Mac / Windows depuis le site.
  • Sur téléphone : cherche « Claude » (par Anthropic) dans l'App Store ou le Play Store. Pratique pour me parler partout, et même créer ton site depuis ton canapé.

Crée ton compte avec ton adresse mail (ou ton compte Google), tu reçois un code, et c'est parti.

2

Passer à l'abonnement Pro (~20 $/mois)

La version gratuite te laisse me parler un peu, mais pour construire un site on a besoin de plus de place et des outils de création. L'abonnement de base, « Pro », coûte environ 20 $ par mois (le prix exact peut varier un peu). Sans engagement : tu peux arrêter quand tu veux.

  1. Dans Claude, clique sur ton nom (en bas à gauche) puis sur « Mettre à niveau » / Upgrade.
  2. Choisis Pro, entre ta carte bancaire, valide.
Mon conseil de modèle : dans le menu en haut de la conversation, choisis Sonnet 5.5. C'est le meilleur point de départ : rapide, très bon pour créer des sites, et il consomme peu de ton quota.
3

Créer ton compte GitHub

GitHub, c'est comme un Google Drive pour les sites et le code. Et c'est gratuit. C'est aussi là que ton site va vivre sur internet.

  1. Va sur github.com/signup.
  2. Entre ton adresse mail, un mot de passe, et surtout un nom d'utilisateur (ex : alois-dupont). Il apparaîtra dans l'adresse de ton site, choisis-le bien !
  3. Résous le petit puzzle « je ne suis pas un robot », puis valide le code reçu par mail.
  4. Quand GitHub pose des questions (« tu es étudiant ? », etc.), tu peux cliquer sur Skip / Passer. Choisis l'offre Free.
4

Créer ton premier « repo »

Un repo (« dépôt »), c'est juste un dossier sur GitHub qui contient les fichiers de ton site.

  1. Sur GitHub, clique sur le + en haut à droite puis New repository.
  2. Repository name : un nom court, sans espaces ni accents. Ex : mon-site.
  3. Coche Public (obligatoire pour le gratuit).
  4. Coche « Add a README file ». Ça crée directement un premier fichier, et le dossier n'est pas vide.
  5. Clique sur Create repository. C'est fait !
5

Brancher GitHub à Claude

C'est l'étape qui fait la magie : une fois reliés, je peux écrire directement dans ton repo, sans que tu copies-colles quoi que ce soit.

  1. Sur claude.ai/code (ou dans l'application, onglet Code), Claude te propose de connecter GitHub.
  2. Clique, connecte-toi à GitHub, et autorise l'application « Claude ».
  3. GitHub te demande à quels repos donner accès : choisis « Only select repositories » et sélectionne uniquement ton repo mon-site. Tu gardes le contrôle.
  4. De retour dans Claude, choisis ce repo, et tu peux me demander ton site.
Les menus bougent de temps en temps. Si tu ne trouves pas un bouton, demande-moi : « je suis perdu, où est le bouton pour connecter GitHub ? ». Fais une capture d'écran et envoie-la-moi, je te guide.
Plan B sans connexion : demande-moi de te faire un fichier index.html dans une conversation normale, télécharge-le, puis dans ton repo GitHub clique sur Add file → Upload files et glisse-le dedans. Ça marche aussi !
6

Mettre ton site en ligne (GitHub Pages)

GitHub Pages est un service gratuit qui transforme ton repo en vrai site internet, avec une adresse que tu peux envoyer à tout le monde.

  1. Dans ton repo, clique sur l'onglet Settings (⚙️, en haut).
  2. Dans le menu à gauche, clique sur Pages.
  3. Sous Build and deployment → Source, choisis « Deploy from a branch ».
  4. Sous Branch, choisis main et le dossier / (root), puis clique sur Save.
  5. Attends 1 à 2 minutes, recharge la page : l'adresse apparaît en haut :
    https://TON-PSEUDO.github.io/mon-site/
Il faut un fichier nommé index.html à la racine du repo : c'est la page d'accueil. Je le crée pour toi, tu n'as qu'à me le demander.

Ce soir : ton premier site

Une fois les 6 étapes faites, ouvre une conversation avec moi (en Sonnet 5.5), repo sélectionné, et colle ça, en le personnalisant :

Salut Claude ! Je suis débutant complet, je n'y connais rien en code. Crée-moi un site d'une seule page (fichier index.html) pour me présenter. Infos sur moi : je m'appelle Aloïs, j'aime [mes passions], je fais [mon activité]. Je veux : un titre accrocheur, une courte présentation, une section « mes passions », et une façon de me contacter. Style : moderne, sobre, lisible sur téléphone. Écris le fichier dans mon repo, puis explique-moi simplement ce que tu as fait.

Quand c'est fait, attends 1 à 2 minutes, ouvre l'adresse de ton site : tu es en ligne. Ensuite, joue : « change les couleurs », « ajoute une photo », « mets un fond étoilé », « ajoute un petit jeu ». Un message, un changement.

Astuce de pro : tu es bloqué ? Ce n'est pas grave, c'est le jeu. Écris « explique-moi comme si j'avais 10 ans ». Ça marche à tous les coups.
